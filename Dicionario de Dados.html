Dicionário de Dados Conceitual

Os exemplos de valores abaixo são fictícios, usados apenas para ilustrar o tipo de dado.

PACIENTE

PACIENTE = id_paciente + nome_completo + data_nascimento + sexo + cpf + rg + profissao + estado_civil + endereco + telefone + email + responsavel_legal + historico_saude + data_cadastro

Atributo Tipo físico Obrigatório Significado e relevância
id_paciente integer Sim (PK) Identificador único do paciente.
nome_completo varchar(150) Sim Nome completo do paciente.
data_nascimento date Sim Data de nascimento do paciente.
sexo varchar(30) Sim Sexo registrado no cadastro do paciente.

DENTISTA

DENTISTA = id_dentista + nome + cro + especialidade + telefone

Atributo Tipo físico Obrigatório Significado e relevância
id_dentista integer Sim (PK) Identificador único do dentista.
nome varchar(120) Sim Nome completo do dentista.
cro varchar(20) Sim Número de registro profissional no CRO.
especialidade varchar(80) Sim Especialidade do dentista.
telefone varchar(20) Não Telefone de contato profissional.

CONSULTA

CONSULTA = id_consulta + id_paciente + id_dentista + data + horario + status + procedimento + observacoes + tipo_pagamento

Atributo Tipo físico Obrigatório Significado e relevância
id_consulta integer Sim (PK) Identificador único da consulta.
id_paciente integer Sim (FK) Paciente vinculado à consulta.
id_dentista integer Sim (FK) Dentista responsável pela consulta.
data date Sim Data marcada para a consulta.
horario time Sim Horário marcado para a consulta.
status varchar(30) Sim Situação atual da consulta.
